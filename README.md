# Thai Daily News 2.5.1

แอปอ่านข่าวไทยและต่างประเทศบน Android และคอมพิวเตอร์ ใช้ Google Apps Script เดิมรับ RSS ตามรอบเวลา แสดงข่าวจากฐานข้อมูลที่เตรียมไว้ และเตรียมสรุปไทยผ่าน OpenRouter เดิมเมื่อเปิดอ่านข่าวที่มีเนื้อหาเพียงพอ

## อ่านเนื้อหาในแอป

- ใช้ RSS description/summary และ content:encoded หรือ Atom content โดยเลือกข้อความที่ให้รายละเอียดมากกว่า เก็บย่อหน้าจากต้นฉบับได้ประมาณ 1,200 ตัวอักษร แยกจากข้อความบนการ์ด 320 ตัวอักษร
- หากข้อความสั้น ระบบลองอ่านคำบรรยายที่สำนักข่าวเผยแพร่ไว้ใน metadata โดยใช้คำขอเดียวกับภาพ สูงสุด 8 ข่าวต่อรอบ และพักข่าวที่ตรวจแล้ว 6 ชั่วโมง ไม่หลบข้อจำกัดเว็บไซต์หรือดึงบทความทั้งฉบับ
- เปิดหน้าอ่านแล้วเตรียมสรุปไทยให้อัตโนมัติ ใช้เนื้อหาที่ยาวขึ้นและ cache ของบริการเดิม คงเพดานรวม 10 คำขอสรุปใหม่ต่อวันสำหรับทั้งระบบ การใช้ OpenRouter อาจมีค่าบริการตามโมเดลเดิม เมื่อครบโควตายังอ่านย่อหน้าจากสำนักข่าวได้
- ข่าวที่มีเพียงพาดหัวจะแจ้งว่าข้อมูลไม่พอ และไม่เรียก AI เพื่อเดารายละเอียด โดยเฉพาะรายการ Google News ที่ description เป็นรายชื่อข่าวอื่น การอ่านทุกข่าวจนจบยังต้องเปิดสำนักข่าวต้นฉบับ

เว็บ: https://basssg.github.io/Thai_Daily_News/

Android: https://github.com/BassSG/Thai_Daily_News/releases/latest

## เริ่มใช้งาน

1. Android: ดาวน์โหลด `Thai-Daily-News.apk` จาก Releases เปิดไฟล์และอนุญาตติดตั้งจากแหล่งที่คุณเลือก หากระบบถาม รุ่น 2.5 ติดตั้งทับรุ่น 2.0–2.4 ได้ด้วยกุญแจลงนามเดิม
2. เปิดแอป ไปที่ตั้งค่า แล้วเลือกเปิดการแจ้งเตือนและอนุญาตใน Android เลือกระดับ Alert เป็น ด่วนเท่านั้น, สมดุล หรือทุกสัญญาณ พร้อมเลือกหมวดและช่วงพักกลางคืนได้
3. เพิ่มวิดเจ็ตจากหน้าตั้งค่าในแอป หรือกดค้างบนหน้าจอหลัก → วิดเจ็ต → Thai Daily News มี 2×2, 4×2 และ 4×4 พร้อมภาพข่าวจริง แต่ละชิ้นเลือกหมวด ข่าวล่าสุด/ข่าวสำคัญ/บันทึกไว้ ธีม และเปิด–ปิดภาพได้จากรูปเฟือง ปรับขนาดบนหน้าจอหลักต่อได้ วิดเจ็ตที่มีอยู่เปิดภาพให้อัตโนมัติหลังอัปเดต
4. คอมพิวเตอร์: เปิดเว็บด้วย Chrome/Edge แล้วติดตั้งจากปุ่มในแอป หรือเมนูเบราว์เซอร์ → ติดตั้งเว็บไซต์เป็นแอป
5. การแจ้งเตือนเว็บต้องเปิดจากเบราว์เซอร์ที่รองรับ Web Push และอนุญาตการแจ้งเตือนก่อน

Android ใช้งานได้ตั้งแต่ Android 8 ขึ้นไป การตรวจข่าวเบื้องหลังเริ่มจากรอบประมาณ 15 นาทีตาม JobScheduler และอาจช้าลงตามโหมดประหยัดแบตเตอรี่/การจัดการแอปของผู้ผลิต การ force-stop แอปจะหยุดงานเบื้องหลังจนกว่าจะเปิดแอปอีกครั้ง วิดเจ็ตมีปุ่มอัปเดตและแสดงเวลาข้อมูลล่าสุด

## ประสบการณ์อ่านรุ่น 2.5

- หน้าหลักให้ภาพข่าวและพาดหัวนำ พร้อมข่าวรองสองเรื่องบนคอมพิวเตอร์ ย่อแผงสถานการณ์เป็นแถบเดียวที่แตะไปยังข่าวสำคัญและกระแสได้
- สลับรายการข่าวและการ์ดภาพได้ และจำรูปแบบที่เลือกไว้ รวมถึงปรับขนาดตัวหนังสือในหน้าอ่านข่าว
- ธีม Daylight และ Midnight พร้อมสีแถบระบบ Android ที่เข้ากัน ใช้ธีมสว่างเป็นค่าเริ่มต้นสำหรับการติดตั้งใหม่
- แยกหน้าตั้งค่าเป็นแท็บ การแจ้งเตือน / การอ่าน / วิดเจ็ต / เกี่ยวกับ รองรับแป้นพิมพ์และโปรแกรมอ่านหน้าจอ
- ค้นหาจากปุ่มแว่นขยายบนมือถือ มีปุ่มล้างตัวกรองเมื่อค้นหาไม่พบ และสลับหน้าโดยไม่ติดตัวกรองจากหน้าเดิม
- เมื่อมีข่าวใหม่ระหว่างเลื่อนอ่าน ระบบเตรียมข้อมูลไว้และแสดงปุ่มให้แตะอัปเดต เพื่อรักษาตำแหน่งการอ่าน
- หน้าอ่านมีปุ่มเปิดต้นฉบับโดยตรง ภาพและเครดิตสำนักข่าว ปุ่มบันทึก/แชร์ และรายงานอื่นในประเด็นเดียวกัน

## ระบบคัดสัญญาณข่าว

- `ข่าวด่วน`: เหตุฉุกเฉิน ภัยพิบัติ คำเตือนที่กระทบวงกว้าง หรือความเปลี่ยนแปลงระดับประเทศที่ใหม่มาก
- `ข่าวใหญ่`: เรื่องผลกระทบสูงที่มีหลักฐานเพียงพอ เช่น หลายสำนักรายงานตรงกัน หรือเป็นประกาศ/มติสำคัญ
- `กำลังเป็นกระแส`: หลายสำนักเริ่มรายงานเหตุการณ์เดียวกัน ระบบแสดงให้จับตาแต่ค่าเริ่มต้นยังไม่ส่ง Alert
- `เริ่มเป็นกระแส`: สัญญาณใหม่ที่มีอย่างน้อยสองแหล่งและมีผลกระทบพอสมควร
- หน้า “วันนี้” เน้นข่าวไทย ข่าวต่างประเทศจะเข้าพื้นที่เด่นและ Alert เฉพาะเหตุที่ผ่านเกณฑ์ข่าวด่วนหรือข่าวใหญ่ ข่าวล่าสุดทั้งหมดยังอ่านได้ในแท็บ “ล่าสุด”
- เรื่องเดียวกันจากหลายสำนักถูกรวมด้วยหัวข้อ เวลา และหมวด พร้อมแสดงจำนวนแหล่งข่าว ลดการแจ้งเตือนซ้ำด้วย `topic_id`
- ค่า Alert เริ่มต้นคือ `สมดุล` ส่งเฉพาะข่าวด่วนและข่าวใหญ่ มีระยะพัก 30 นาทีสำหรับข่าวใหญ่ ข่าวด่วนข้ามระยะพักและช่วงพักกลางคืนได้ แต่ยังป้องกันเรื่องเดิมซ้ำ
- Android แยกช่องระบบเป็น “ข่าวด่วน” ระดับสูงและ “ข่าวใหญ่และประเด็นสำคัญ” ระดับปกติ ผู้ใช้ปรับเสียงและความเด่นของแต่ละช่องได้จากการตั้งค่าระบบ

## ภาพในวิดเจ็ต

- 2×2: ภาพและหัวข่าวทีละเรื่อง แตะลูกศรก่อนหน้า/ถัดไปพร้อมเลขลำดับ เช่น 3/20 ข่าวสุดท้ายวนกลับเรื่องแรก
- 4×2: ภาพย่อข้างหัวข้อข่าว แตะลูกศรเพื่อเปลี่ยนชุด จำนวนเรื่องต่อชุดปรับตามพื้นที่ที่มี พร้อมเลขช่วง เช่น 3–4/20
- 4×4: รายการภาพย่อ หัวข้อ สำนักข่าว และเวลา เลื่อนขึ้น–ลงได้จริง แตะข่าวหลังเลื่อนเพื่อเปิดเรื่องนั้น รองรับทั้ง Midnight และ Ivory
- โหมด “ข่าวสำคัญ” ในวิดเจ็ตใช้ชุดข่าวที่ผ่านเกณฑ์ Alert แทนการเรียงข่าวทั่วไปด้วยความใหม่เพียงอย่างเดียว
- แต่ละวิดเจ็ตแสดงข่าวสูงสุด 20 เรื่องในหมวด/รูปแบบที่เลือก การเปลี่ยนเรื่องไม่เรียก GAS อีก ข่าวที่เลือกบน 2×2/4×2 จำด้วยรหัสข่าว จึงคงเรื่องเดิมระหว่างอัปเดตหากยังอยู่ในชุด เมื่อเปลี่ยนตัวกรอง/ธีมจากรูปเฟืองจะเริ่มเรื่องแรก
- ใช้ `image_url` จาก GAS เดิม ดาวน์โหลดภาพข่าวที่กำลังดูและเตรียมชุดถัดไป/รายการเลื่อน เก็บภาพย่อ 320×200 ใน cache ของ Android ภาพที่ส่งในรายการเลื่อนย่อเหลือ 128×80 เพื่อจำกัดหน่วยความจำ อ่านภาพที่โหลดแล้วได้เมื่อไม่มีเครือข่าย ข่าวที่ไม่มีรูป/โหลดไม่ได้ยังมีหัวข้อและลิงก์เดิม
- รวม URL ซ้ำระหว่างวิดเจ็ต จำกัดดาวน์โหลด 20 รูป/รอบ ภายในงบเวลาประมาณ 25 วินาที ขนาดต้นทางไม่เกิน 4 MB ต่อรูป และ cache ไม่เกิน 10 MB/96 ไฟล์ ลองรูปที่โหลดไม่สำเร็จอีกครั้งหลังพัก 30 นาทีในกระบวนการแอป ไม่มี API รูปแบบเสียเงิน แต่ใช้ดาต้าอินเทอร์เน็ตของเครื่อง
- Android 12 ขึ้นไปใช้ RemoteCollectionItems ส่วน Android 8–11 ใช้ RemoteViewsService ที่ป้องกันด้วย BIND_REMOTEVIEWS วิดเจ็ตเปลี่ยนข่าวด้วยการแตะหรือเลื่อนตามที่ผู้ใช้เลือก ไม่มีการตั้งเวลาหมุนข่าวทุกไม่กี่วินาที

## ระบบข่าว

- รับ RSS 15 ฟีด จาก InfoQuest, มติชน, ข่าวสด, THE STANDARD, Bangkok Post, BBC, Al Jazeera, Google News RSS เสริม และ RSS ทางการของกรมอุตุนิยมวิทยาสำหรับประกาศเตือนภัย/แผ่นดินไหว แยกหมวดการเมือง สังคม อาชญากรรม เศรษฐกิจ ต่างประเทศ และเทคโนโลยี
- รูปข่าวรับจาก Media RSS, enclosure และรูปในข้อความย่อของฟีด หากแหล่งตรงที่รองรับไม่มีรูปในฟีด จะอ่านเฉพาะ Open Graph/Twitter image metadata จากหน้าข่าว สูงสุด 8 หน้าต่อรอบและพักลองซ้ำ 6 ชั่วโมง ไม่ดึงเนื้อหาเต็มมาแสดง ไม่ใช้ API ค้นหารูปแบบเสียเงิน ไม่ใช้รูปสต็อกแทนข่าว
- แสดงรูปใหญ่ในข่าวเด่น ภาพย่อในรายการ และภาพพร้อมเครดิตในหน้ารายละเอียด โหลดภาพย่อเมื่อใกล้หน้าจอ เก็บเฉพาะ URL ภาพใน GAS; ภาพจริงโหลดจากสำนักข่าว หากไม่มีรูปหรือโหลดไม่ได้ยังอ่านข่าวแบบข้อความได้
- Google News RSS เป็นช่องทางเสริมที่ไม่มี SLA ที่ยืนยันสำหรับแอปนี้ สถานะแต่ละแหล่งแสดงในหน้าตั้งค่า
- ตัวรับข่าวตรวจทุก 5 นาที แต่ละฟีดมีรอบ 5–15 นาที หน้าเว็บที่เปิดอยู่ดึง snapshot ใหม่อัตโนมัติทุก 5 นาทีและเมื่อกลับเข้าแอป เก็บ metadata ล่าสุดไม่เกิน 72 ชั่วโมง/360 ข่าว และลดจำนวนอัตโนมัติตามพื้นที่ Script Properties
- ข้อมูลเก็บเป็น gzip/base64 แบบแบ่งส่วนและสลับชุดหลังเขียนสำเร็จ ข้อผิดพลาดของแหล่งหนึ่งไม่ลบข่าวที่เก็บไว้
- ไม่เรียก Brave ในเส้นทางรับข่าว เปิดอ่าน ค้นหา หรือรีเฟรชหน้าอ่าน
- แสดงหัวข้อ/ข้อความย่อและเครดิตสำนักข่าว เนื้อหาเต็มเปิดที่ต้นฉบับ ไม่มีการดึงทั้งเว็บไซต์ผ่าน public proxy
- สรุป/แปลภาษาไทยผ่าน OpenRouter ใช้ `OPENROUTER_API_KEY` และ `ANALYZE_MODEL_PRI` ใน Script Properties เดิม จำกัดคำขอสรุปใหม่รวม 10 ครั้งต่อวัน และเก็บผลเพื่ออ่านซ้ำ แสดงขอบเขตว่าสรุปจากหัวข้อ/ข้อความย่อ
- Desktop Web Push ใช้ VAPID และข้อความ push แบบไม่มี payload; service worker พยายามโหลดข่าวล่าสุดเพื่อประกอบการแจ้งเตือน หากโหลดไม่ได้แสดงข้อความทั่วไปที่ไม่แต่งรายละเอียด
- Android มี cache ในเครื่อง, native notifications, native AppWidgets, native share และ background JobScheduler ส่วนหน้าอ่านใช้ web UI ที่บรรจุใน APK และเรียก GAS ผ่าน HTTPS ฝั่ง Android

## พัฒนาและตรวจสอบ

```sh
npm ci
npm run build
npm test
npm run preview
```

`npm run build` สร้างไอคอน, GAS HTML, crypto bundle และสำเนา web assets สำหรับ Android จาก source หลัก ตัวทดสอบ Node ตรวจวันข่าว, URL, dedup, ลำดับความใหม่, ตัวกรองแจ้งเตือน และลายเซ็น ES256

Android ใช้ Java 17, Gradle 8.13, AGP 8.11.1 และ compile/target SDK 36 Workflow `Android application` สร้าง release APK ที่เซ็นด้วยกุญแจประจำแอป พร้อม lint และ smoke test บน Android emulator ตรวจ API จริง หน้าอ่าน รายละเอียด บันทึก การตั้งค่า ภาพข่าวผ่าน native AppWidgetHost สามขนาด การบันทึกตัวเลือกภาพแยกวิดเจ็ต ขนาด bitmap กรณีไม่มีภาพ และแจ้งเตือนทดสอบ

## ปรับ GAS

ตั้งค่า `.clasp.json` ส่วนตัวให้ชี้ script เดิมและ `rootDir: "gas"` แล้วใช้ `clasp push` สร้าง version และอัปเดต deployment เดิมให้ตรงกัน หน้า GitHub และ native Android ใช้ deployment URL เดียวที่อยู่ใน `config.js` และ `NewsRepository.java`

ฟังก์ชันติดตั้ง/ตัวรับข่าวภายในลงท้าย `_` เพื่อปิดการเรียกจาก `google.script.run` ทริกเกอร์เรียก `refreshNewsScheduled_` ไม่ต้องรันติดตั้งซ้ำในการแก้ UI ปกติ

ไฟล์ `.private/`, `.clasp.json`, และ `gas/PrivateBootstrap.js` ไม่เข้า Git กุญแจลงนาม APK เก็บในเครื่องเจ้าของและ GitHub Secrets ห้ามเปลี่ยนกุญแจในรุ่นถัดไปหากต้องการติดตั้งอัปเดตทับ การติดตั้งครั้งแรกใช้ bootstrap token ส่วนตัวแบบใช้ครั้งเดียว หลังติดตั้งต้องแทนที่ PrivateBootstrap ด้วย implementation ที่ปิดใช้งานแล้วและ deploy version ใหม่
